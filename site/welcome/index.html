What is left to do

Sign in

There is no password. Use GitHub, or get a one-time link by email. Signing in makes the account your subscription belongs to.

Sign in with the address you paid with, so the payment is matched to you.

Sign in Continue with GitHub Email me a sign-in link

Link your install

In Claude Code, run this command. It opens a page with a short code.

/p0ssess:pro

Check that the code matches the one in your terminal, then press Link. Pro turns on in the session that is already running, with no restart and nothing to paste.

No plugin yet? Install p0ssess first, then run the command.

Receipts and cancelling

Polar emails a confirmation to the address you paid with. Your invoices and your card are in Polar’s customer portal, and so is cancelling. You sign in there with that same address.
