Questions before you install

Short answers, with the page that holds the long one. Write to support@p0ssess.me for anything else.

What leaves my machine?

Your prompts and files go only to the model you hand a job to, through your own OpenRouter key, and every call tells OpenRouter not to route to providers that train on prompts. The p0ssess service never sees a prompt, a file or a file name. To rank routes it gets a short task description, sizes, the stakes and your model limits, and it keeps no request logs.

Files that look like secrets (.env, keys, credentials) never leave, and a .p0ssess-private file blocks all delegation from a repository. Anonymous outcome records, one line for each finished run with no prompt or file in it, are on by default and one sentence turns them off. With Pro, the cloud sandbox receives the files git tracks so it can run them. Privacy policy

Can it spend more than I allow?

The limits are enforced by the tools that spend. A new install starts at $1 a day, $10 a month and $0.25 a task. The daily limit warns, the monthly cap stops paid runs, and a job over the task amount waits for one yes from you.

Each call’s maximum is reserved before it is sent, so parallel calls cannot overshoot, and rescue never spends past your limits. A repository’s own rules file can only tighten them.

What happens when my OpenRouter credit runs out?

The hand-off stops and says so in one line: Your OpenRouter balance is too low for this run. Add credits at https://openrouter.ai/settings/credits, then ask again. A run that fails before it reaches a model costs nothing. Claude itself is untouched, so the work can stay with Claude until you top up.

Does p0ssess touch my Claude account?

It never reads, stores or relays your Claude credentials. To know when a window is nearly used up, it reads the usage figures Claude Code reports to its own status line, on your machine.

What does rescue move, and what stays with Claude?

Rescue takes routable work: research, summaries, bulk and media work, and code edits that fit. Critical work, such as auth, infrastructure, production and money, is never moved silently. Claude names the model and the cost and asks once for that task. Keep this on Claude always wins, and turn rescue off ends it.

Is the saving a real number?

It is a price-list comparison, and your p0ssess page says so. Each run’s tokens are priced at Claude’s list price and set against what OpenRouter charged for the same call. A Claude run could have taken more or fewer tokens, and Claude’s own planning and checking is billed as usual, so what a job saves depends on the job. Runs where Claude would have been cheaper are counted and shown.

Do I need Pro to save money?

No. Routing, rules, budgets, receipts and the savings figures are all in the free plugin, and the unit-test runs on this page used it. Pro adds rescue, the monthly report by email and the cloud sandbox.

How do I cancel, and what happens then?

Polar runs the checkout and gives you a portal to cancel or change plans. When Pro ends you drop back to Free and the routing keeps working. Refunds are set out in the refund policy.

Where does it run?

On Linux (amd64 and arm64), macOS on Apple silicon and Windows x64, with Claude Code 2.1.319 or later. Media, read-only and one-shot jobs work everywhere. Coding hand-offs need a sandbox: rootless podman on Linux, or Pro’s cloud sandbox on macOS and Windows.

Install the free plugin

Two commands and an OpenRouter key. The tour opens in your first session and takes about a minute.

  1. Add the plugin to Claude Code.

    claude plugin marketplace add <repository URL>
claude plugin install p0ssess@p0ssess

  2. Put your OpenRouter key where p0ssess reads it.

    mkdir -p ~/.config/p0ssess/secrets
install -m 600 /dev/null ~/.config/p0ssess/secrets/openrouter_key
"${EDITOR:-vi}" ~/.config/p0ssess/secrets/openrouter_key

  3. Start Claude Code. The tour shows your limits, runs one live demo capped at a cent, and tells you where to see spend. Settings changes wait for your yes, and p0ssess setup undo reverts them.

What you need

Claude Code 2.1.319 or later, on any Claude plan or an API key, and an OpenRouter API key for the other models to bill to. The local sandbox for coding work needs Linux with rootless podman. On macOS and Windows, media and one-shot jobs work without it, and Pro’s cloud sandbox covers the rest.
