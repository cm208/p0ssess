Install

Claude, now with everything it can’t do.

p0ssess is a Claude Code plugin that turns other models into Claude’s subagents. Claude hands them work the way it hands work to its own subagents: a possessed Haiku agent carries the job through OpenRouter to a model that can watch video, hear audio or make images, and returns only the answer. Claude stays in charge, within your budget and rules.

Three things Claude couldn’t do before

Ask the way you normally would. When a job needs video, audio or an image, Claude hands it to a model that can do it and answers from what comes back, with the model and its price in a few words. It asks first only when the estimate is above your limit.

  • Watch video

    You say: Watch bug-repro.mp4 and tell me where it breaks.

    Screen recordings, talks, whole films. On a measured call, a ten-second test clip came back described correctly, down to the tone on its soundtrack.

    You say: Transcribe standup.m4a and list the action items.

    Meetings and voice memos, or the soundtrack of a video. On a measured call, 16 seconds of speech came back word for word, with timestamps.

  • Make and edit images

    You say: Make an image of a ghost holding a lantern.

    Icons and illustrations, or a retouched screenshot. On a measured call, a 1024-pixel image matched its prompt. It lands as a file and Claude prints the path.

    $0.0070measured, on recraft-v4.1-flash

Each price is the other model’s bill for one call. The hand-off itself costs Claude a few cents more, so p0ssess keeps it for work Claude can’t do or shouldn’t spend itself on. Small edits and plain questions never leave Claude.

How a possession works

Other models join your session as subagents. Claude starts one with the same Agent tool it uses for its own, in one sentence. That subagent is a small Haiku, possessed: it never does the job itself. It carries the request to the other model and passes the answer back word for word.

Claude never reads the video, the raw tool output or the other model’s transcript, so the work doesn’t fill your conversation. After ten minutes of film its context stood at 28,883 tokens, against 28,555 when it worked alone.

Then Claude does what it does with any subagent’s work: checks it, uses it and answers you. Code edits come back as a diff from a separate git worktree, and nothing lands until Claude has read it.

An engine picks who does the job

For each job, the Predictive Model Engine scores every model that could do it, Claude included. A score is a cautious estimate, out of 100, that the result will be accepted. It comes from licensed benchmarks, p0ssess’s own checks and your history.

Each level of stakes has a gate, and a model that scores below it isn’t considered. The violet part of each line is the scores that clear.

And the work Claude shouldn’t spend itself on

Beyond new senses, the same hand-off covers chores, second opinions and the last stretch of a usage window. The prices in this section are the engine’s estimates.

Tedious code, in a sandbox

You say: Use deepseek flash to draft tests for stats.py.

For chores the tests can judge, a cheap coding model works in its own sandbox, on a separate git worktree. The edits come back as a diff. Claude reads it and runs the tests before anything lands.

You set the limits

A monthly cap and a per-task limit, enforced by the tools that spend. Under the limit a job just runs. Above it, Claude asks first, in one line with the cost.

Rules in your own words

  • Never use grok.
  • Only use gemini-3.8-flash for video.
  • Auto-approve video summaries up to 20 cents each today.

Claude shows the rule it wrote in one line and saves it when you confirm. A cloned repository’s rules can only tighten yours.

A sandbox for agent work

Coding agents run in a rootless podman sandbox with no access to your home directory, SSH keys or credentials, and no route to your local network. Your OpenRouter key stays in a proxy the model can’t reach.

What it won’t do

  • Send prompts to providers that train on them.
  • Spend past your monthly cap.
  • Hand off critical work, such as auth, infrastructure, production or money, unless your rule allows it.
  • Create a rule or a standing approval on its own.
  • Send secrets, or anything from a repository marked .p0ssess-private.
  • Read, store or relay your Claude credentials.
  • Patch or preload into Claude Code.
  • Phone home. History stays local, without prompt text.

Install p0ssess

Two commands and an OpenRouter key. Releases are served from the project’s own git server, next to the source, so you can see exactly what you run.

  1. Add the plugin to Claude Code.

    claude plugin marketplace add <repository URL>
claude plugin install p0ssess@p0ssess

  2. Put your OpenRouter key where p0ssess reads it.

    mkdir -p ~/.config/p0ssess/secrets
install -m 600 /dev/null ~/.config/p0ssess/secrets/openrouter_key
"${EDITOR:-vi}" ~/.config/p0ssess/secrets/openrouter_key

  3. Start Claude Code and run /p0ssess:p0ssess-me. Then ask it to watch something. Settings changes wait for your yes, and p0ssess setup undo reverts them.

What you need

  • Claude Code 2.1.319 or later, on any Claude plan (Pro, Max, Team or Enterprise) or an API key.
  • An OpenRouter API key. Other models bill to it.
  • For the agent sandbox, Linux with rootless podman. Without it, media and one-shot jobs still work.
  • Go 1.27 or later, only when a checkout has to build the binary itself.
